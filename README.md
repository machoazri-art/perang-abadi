# Perang Abadi

Permainan RPG berasaskan teks dalam Bahasa Melayu Malaysia.

## Cara bermain
1. Buka permainan melalui GitHub Pages atau hos web statik.
2. Masukkan nama pahlawan dan mulakan pengembaraan.
3. Lawan musuh untuk memperoleh XP dan emas.
4. Tingkatkan tahap, beli ramuan dan ambil haiwan peliharaan untuk membantu dalam pertempuran.
5. Simpan kemajuan permainan pada peranti atau eksport fail simpanan sebagai sandaran.

## Ciri-ciri
- Sistem pertempuran berasaskan giliran.
- Lima kawasan dengan musuh dan bos.
- Sistem tahap, XP, emas dan ramuan.
- Haiwan peliharaan dengan kebolehan tersendiri.
- Simpan, import dan eksport kemajuan permainan.
- Sokongan PWA untuk pemasangan pada peranti.

## Teknologi
HTML, CSS dan JavaScript tulen. Data permainan disimpan menggunakan `localStorage`.
